# 3 分钟演示视频脚本（Demo Mode）

> 建议全程使用 Demo Mode（▶ 一键演示 → 教学—学习—科研一体化），不依赖真实 LLM API。

## 0:00–0:20 开场定位

- 首页：平台定位“让每一门计算机课程拥有自己的 AI 学习与教学空间”。
- 点击“▶ 一键演示”，选择“教学—学习—科研一体化（操作系统）”，顶部出现 DEMO 状态条。

## 0:20–0:55 教师：发现问题 → AI 诊断 → 教学方案

- 教师端“教学诊断”：班级平均掌握度 58%，进程同步 42%。
- 点击“生成诊断”：“多数学生能记忆互斥与同步定义，但 P/V 操作顺序与应用存在困难”。
- 采用建议 → AI 教学设计：生成第 4 章教学方案（流程/案例/随堂练习/编程实验）。

## 0:55–1:50 学生：课程学习 → 讲堂 → 答疑 → 代码实验

- 切换为学生，进入“我的课程 → 操作系统”。
- AI 课程讲堂：选择“第4章 进程同步”，展示结构化课程（临界区→互斥→信号量→P/V→生产者消费者），
  页面显示“本次讲解依据：课程官方 PPT / 指定教材”。
- 课程答疑：问“为什么生产者和消费者都需要使用信号量？”，回答带引用来源与知识点。
- 作业与实验：查看最近提交（8/12 Wrong Answer）→ AI 错误诊断 → “开始针对性复习”。

## 1:50–2:20 学习中心：画像与个性化

- 学习中心：进程同步 42% → AI 分析 → 今日任务（复习信号量/学习生产者消费者/重做同步代码题），每项都有推荐原因。
- 考前冲刺计划：选择考试日期生成倒计时计划；错题本按知识点聚合。

## 2:20–2:55 科研：从课程进入研究

- 课程知识图谱：点击带 📄 的知识点 →“深入研究”→ 相关论文（含推荐理由）。
- 论文阅读：原文 + AI 总结 + 引用来源；“回到课程知识”跳转。

## 2:55–3:00 收尾

- 一键重置演示 → 退出演示，恢复真实账户，数据零污染。
