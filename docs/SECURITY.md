# 安全与 RBAC 矩阵

## 一、角色与权限矩阵

| 能力 | 教师 | 学生 | 研究模式 | Demo 账户 |
| --- | --- | --- | --- | --- |
| 管理自己课程/作业 | ✓ | ✗ | ✗ | 仅 Demo 数据 |
| 上传官方资料（S） | ✓ | ✗ | ✗ | Demo 内 |
| 审核共享资料（A） | ✓ | 申请 | ✗ | Demo 内 |
| 上传个人资料（P） | ✓ | ✓ | ✓ | Demo 内 |
| 查看本课程学情 | ✓ | 仅自己 | ✗ | Demo 内 |
| 提交作业/查看自己成绩 | ✗ | ✓ | ✗ | Demo 内 |
| 查看他人私有资料/成绩/代码 | ✗ | ✗ | ✗ | ✗ |
| 科研资料（默认私有） | ✓ | ✓ | ✓ | Demo 内 |

## 二、已实现的安全措施

- Token：HMAC-SHA256 签名，7 天有效（`app/api/deps.py`）。
- RBAC：`require_roles` 强制角色；课程资料按 `_enrolled_or_403` 校验选课关系。
- 数据隔离：私有资料按 `owner_id` 过滤；Demo 模式使用独立账户 + 快照重置。
- 上传校验：扩展名白名单 + 文件头魔数（PDF/Office/UTF-8）+ 大小上限。
- 代码安全：当前 Mock Judge，不执行任意用户代码；真实沙箱接入前保持关闭。
- 密钥管理：`.env` 存密钥，`.env.example` 为模板，`.gitignore` 排除真实密钥。
